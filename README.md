# SpeakUp Landing Page

A responsive landing page for **SpeakUp**, a public speaking course platform. The page recreates the provided UI reference using pure HTML and CSS.

## Features

* Responsive layout for desktop, tablet, and mobile screens
* Navigation header with enrollment CTA
* Hero section with course introduction
* Learner statistics and course rating
* Course benefits section
* Curriculum section
* Video preview section
* Learner testimonials and ratings
* Final enrollment call-to-action
* Purple-themed icons and branding
* Provided image assets used directly

## Tech Stack

* HTML5
* CSS3
* Font Awesome icons

No React, Tailwind CSS, Bootstrap, or other frontend frameworks are used.

## Getting Started

### 1. Clone the repository

```bash
git clone https://github.com/akhilbandaru326/speakup-landing-page.git
```

### 2. Open the project

```bash
cd speakup-landing-page
```

### 3. Run the website

Open `index.html` directly in your browser.

No build command or package installation is required.
